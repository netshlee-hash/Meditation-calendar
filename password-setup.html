명상센터 비밀번호 초기 설정

이 페이지는 브라우저에서만 계산합니다. 비밀번호를 서버로 전송하거나 저장하지 않습니다. 관리자와 일반 사용자 비밀번호를 각각 설정하세요.

Google Apps Script → 프로젝트 설정 → 스크립트 속성에 아래 두 항목을 각각 추가하세요.

첫 번째 속성 이름

첫 번째 속성 값

두 번째 속성 이름

두 번째 속성 값

속성 이름과 값을 정확하게 복사해 저장하세요. 비밀번호 자체는 어느 속성에도 입력하지 마세요. 화면을 캡처해 공유하지 않는 편이 좋습니다.

주의: 현재 시스템은 소규모 시범 운영용입니다. 비밀번호 유출 방지를 위해 반복 시도 제한, 비밀번호 변경 시 세션 무효화 등 추가 보호가 필요합니다. 검증값은 Apps Script 기존 코드의 SHA-256 방식과 일치하도록 생성합니다.
